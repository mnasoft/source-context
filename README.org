#+AUTHOR: Микола
#+LANGUAGE: ru

* Введение

=source-context= — Common Lisp утилита для формирования, просмотра
и сохранения контекста исходного кода для передачи LLM.

Поддерживаются три вида контекста:

- =context= — обычный файловый контекст;
- =asdf-context= — контекст на основе компонентов ASDF-системы;
- =git-context= — контекст на основе файлов Git-репозитория.

Контекст содержит корневой каталог и набор файлов. Общий интерфейс
позволяет просматривать состав контекста, вычислять его размер,
рендерить содержимое и сохранять результат в текстовый файл.

* Зависимости

- ASDF / UIOP
- CL-PPCRE
- Git — для использования =git-context=

* Установка

** ~/common-lisp

Разместить проект в стандартном каталоге:

#+begin_src shell
cd ~/common-lisp
git clone <repository-url> source-context
#+end_src

Загрузить систему:

#+begin_src lisp
(ql:quickload :source-context)
#+end_src

Проверить:

#+begin_src lisp
(asdf:find-system :source-context)
#+end_src

** Quicklisp local-projects

Проект можно разместить в:

#+begin_example
~/quicklisp/local-projects/source-context/
#+end_example

и загрузить:

#+begin_src lisp
(ql:quickload :source-context)
#+end_src

** Произвольный каталог

Для дерева =~/local-projects/= можно создать файл:

#+begin_example
~/.config/common-lisp/source-registry.conf.d/50-local-projects.conf
#+end_example

с содержимым:

#+begin_src lisp
(:tree "~/local-projects/")
#+end_src

После изменения source registry в работающем Lisp:

#+begin_src lisp
(asdf:clear-source-registry)
#+end_src

* Обычный контекст

Обычный =context= представляет набор файлов относительно общего
корневого каталога.

Сначала создаётся пустой контекст:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-context
   #p"~/quicklisp/local-projects/LLM/source-context/"))
#+end_src

После этого в него можно собрать файлы по регулярному выражению:

#+begin_src lisp
(source-context:source-context
 *ctx*
 :regexp "\\.(lisp|asd|org)$")
#+end_src

При рекурсивном сборе обычного файлового контекста по умолчанию
исключаются каталоги =.git= и =generated=.

Дополнительные исключения можно задать при создании:

#+begin_src lisp
(source-context:make-context
 #p"~/common-lisp/acad/dxf/"
 :exclude-directories '(".git" "generated" "build")
 :exclude-files '("-generated\\.lisp$" "/test/"))
#+end_src

* ASDF context

Для Common Lisp проекта контекст можно сформировать непосредственно
из дерева компонентов ASDF-системы:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-asdf-context "source-context"))
#+end_src

В контекст включаются исходные файлы, найденные в дереве компонентов
ASDF.

Файл определения системы =.asd= включается по умолчанию.

Отключить его можно параметром =:include-asd-p=:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-asdf-context
   "source-context"
   :include-asd-p nil))
#+end_src

Имя ASDF-системы можно получить через:

#+begin_src lisp
(source-context:context-system-name *ctx*)
#+end_src

Путь к файлу определения системы:

#+begin_src lisp
(source-context:context-asd-file *ctx*)
#+end_src

Структуру компонентов ASDF можно посмотреть:

#+begin_src lisp
(source-context:list-components *ctx*)
#+end_src

* Git context

=git-context= формируется на основе файлов, отслеживаемых Git.

Создать контекст репозитория:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-git-context
   #p"~/quicklisp/local-projects/LLM/source-context/"))
#+end_src

В =make-git-context= необязательно передавать непосредственно корень
репозитория.

Можно указать любой каталог внутри рабочего дерева:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-git-context
   #p"~/quicklisp/local-projects/LLM/source-context/src/"))
#+end_src

Можно также передать отдельный файл:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-git-context
   #p"~/quicklisp/local-projects/LLM/source-context/src/context.lisp"))
#+end_src

Корень Git-репозитория определяется автоматически.

Проверить его можно через:

#+begin_src lisp
(source-context:context-root *ctx*)
#+end_src

Список файлов =git-context= формируется из файлов, возвращаемых
=git ls-files=.

Таким образом, =git-context= представляет состояние файлов,
отслеживаемых Git, а не результат обычного рекурсивного обхода
каталога.

* Просмотр контекста

Все виды контекста используют общий интерфейс.

** Корневой каталог

#+begin_src lisp
(source-context:context-root *ctx*)
#+end_src

** Имя контекста

#+begin_src lisp
(source-context:context-name *ctx*)
#+end_src

Для обычного =context= и =git-context= имя определяется по имени
корневого каталога.

Для =asdf-context= используется имя ASDF-системы.

** Список файлов

#+begin_src lisp
(source-context:list-files *ctx*)
#+end_src

** Краткая сводка

#+begin_src lisp
(source-context:context-summary *ctx*)
#+end_src

Сводка обычного контекста содержит количество файлов, размер,
число символов и примерную оценку количества токенов.

** Размер контекста

#+begin_src lisp
(source-context:context-size *ctx*)
#+end_src

** Количество символов

#+begin_src lisp
(source-context:context-character-count *ctx*)
#+end_src

** Оценка количества токенов

#+begin_src lisp
(source-context:context-token-count *ctx*)
#+end_src

Оценка использует значение =*characters-per-token*=:

#+begin_src lisp
source-context:*characters-per-token*
#+end_src

* Изменение контекста

После создания набор файлов контекста можно изменять вручную.

Добавить файл:

#+begin_src lisp
(source-context:add-file
 *ctx*
 #p"~/common-lisp/acad/dxf/README.org")
#+end_src

Удалить файл:

#+begin_src lisp
(source-context:remove-file
 *ctx*
 #p"~/common-lisp/acad/dxf/test/test-dxf.lisp")
#+end_src

Очистить список файлов:

#+begin_src lisp
(source-context:clear-context *ctx*)
#+end_src

Эти операции возвращают объект контекста, что позволяет продолжать
интерактивную работу с ним.

* Рендеринг

** Отдельный файл

#+begin_src lisp
(source-context:render-file
 *ctx*
 (first (source-context:context-files *ctx*)))
#+end_src

** Весь контекст

#+begin_src lisp
(source-context:render-context *ctx*)
#+end_src

Каждый файл выводится вместе с его относительным именем.

** Получение контекста как строки

#+begin_src lisp
(defparameter *context-text*
  (source-context:context-string *ctx*))
#+end_src

Полученную строку можно использовать непосредственно при работе с LLM
или другими программами.

* Сохранение

Контекст можно сохранить в текстовый файл функцией =write-context=.

** Путь по умолчанию

Если pathname не указан:

#+begin_src lisp
(source-context:write-context *ctx*)
#+end_src

результат сохраняется в:

#+begin_example
~/LLM/<context-name>.txt
#+end_example

Например, для ASDF-системы =source-context=:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-asdf-context "source-context"))

(source-context:write-context *ctx*)
#+end_src

результирующий файл:

#+begin_example
~/LLM/source-context.txt
#+end_example

Для обычного и Git-контекста имя файла определяется именем корневого
каталога.

** Явный pathname

Путь можно указать явно:

#+begin_src lisp
(source-context:write-context
 *ctx*
 #p"~/Downloads/source-context.txt")
#+end_src

В этом случае переданный pathname используется вместо пути по
умолчанию.

* Создание и сохранение одной операцией

Для =asdf-context= и =git-context= определена обобщённая функция
=make-and-write-context=.

Она создаёт специализированный контекст, записывает его в текстовый
файл и возвращает созданный объект.

** ASDF context

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-and-write-context
   'source-context:asdf-context
   "source-context"))
#+end_src

Если pathname результата не указан, будет использован:

#+begin_example
~/LLM/source-context.txt
#+end_example

Явный pathname можно передать третьим аргументом:

#+begin_src lisp
(source-context:make-and-write-context
 'source-context:asdf-context
 "source-context"
 #p"~/Downloads/source-context.txt")
#+end_src

** Git context

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-and-write-context
   'source-context:git-context
   #p"~/quicklisp/local-projects/LLM/source-context/"))
#+end_src

Так же, как и для =make-git-context=, можно указать путь внутри
репозитория:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-and-write-context
   'source-context:git-context
   #p"~/quicklisp/local-projects/LLM/source-context/src/"))
#+end_src

Результирующий объект остаётся доступным для дальнейшей работы:

#+begin_src lisp
(source-context:list-files *ctx*)
(source-context:context-summary *ctx*)
#+end_src

=make-and-write-context= специализирован только для =asdf-context=
и =git-context=.

* Типичная работа в SLY

** ASDF-проект

Создать контекст:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-asdf-context "source-context"))
#+end_src

Посмотреть объект:

#+begin_src lisp
*ctx*
#+end_src

Посмотреть компоненты системы:

#+begin_src lisp
(source-context:list-components *ctx*)
#+end_src

Посмотреть итоговый набор файлов:

#+begin_src lisp
(source-context:list-files *ctx*)
#+end_src

Получить сводку:

#+begin_src lisp
(source-context:context-summary *ctx*)
#+end_src

При необходимости изменить состав:

#+begin_src lisp
(source-context:add-file *ctx* #p"README.org")
#+end_src

Сохранить:

#+begin_src lisp
(source-context:write-context *ctx*)
#+end_src

** Git-репозиторий

Для случая, когда нужен весь набор отслеживаемых Git файлов:

#+begin_src lisp
(defparameter *ctx*
  (source-context:make-git-context
   #p"~/quicklisp/local-projects/LLM/source-context/"))
#+end_src

Проверить состав:

#+begin_src lisp
(source-context:list-files *ctx*)
#+end_src

И сохранить:

#+begin_src lisp
(source-context:write-context *ctx*)
#+end_src

** Короткий вариант

Если промежуточная проверка состава не требуется, ASDF-контекст можно
сформировать и сохранить одной формой:

#+begin_src lisp
(source-context:make-and-write-context
 'source-context:asdf-context
 "source-context")
#+end_src

То же для Git:

#+begin_src lisp
(source-context:make-and-write-context
 'source-context:git-context
 #p"~/quicklisp/local-projects/LLM/source-context/")
#+end_src

* Структура проекта

Основные файлы системы:

#+begin_example
source-context.asd
README.org
src/
  package.lisp
  generics.lisp
  classes.lisp
  context.lisp
  asdf-context.lisp
  git-context.lisp
  methods.lisp
#+end_example

=package.lisp=
содержит определение пакета и публичного API.

=generics.lisp=
содержит определения обобщённых функций.

=classes.lisp=
содержит классы =context=, =asdf-context= и =git-context=.

=context.lisp=
содержит базовые операции над файловым контекстом и функции
статистики.

=asdf-context.lisp=
содержит формирование контекста на основе дерева компонентов ASDF.

=git-context.lisp=
содержит определение корня Git-репозитория и формирование списка
отслеживаемых файлов.

=methods.lisp=
содержит методы просмотра, рендеринга, сохранения и специализированные
методы различных типов контекста.
